# Note Walker

Rhythm-reading games for music class. A little walker crosses a scrolling staff, and players tap on the start of every note.

Opens with the Mansfield Games intro and a menu (`index.html`) with two games:

- **Marathon** (`marathon.html`): one long run that adds half, whole and eighth notes, rests, ties, sixteenths and triplets as you go, at a steady 70 bpm. Three lives, and a high score list saved on each device.
- **Learn** (`learn.html`): nine separate levels, from quarter notes up to sixteenths.

Play: https://vvm26br2pj-max.github.io/note-walker/

Each game is a single HTML file. `build.py` builds `marathon.html` and `learn.html` from the source games in the folder above. Tap with the Space bar, the TAP button or the touchscreen.
