# Note Walker

Rhythm-reading game for music class, now an app for iPhone and iPad: https://apps.apple.com/app/id6836165032

This site holds the app's front page plus the pages the App Store links to:

- `support.html`: the App Store Support URL (help and the bug-report email)
- `privacy.html`: the App Store Privacy Policy URL

Keep both of those online. `marathon.html`, `learn.html` and `levels.html` only send old links to the front page.
