# Note Walker

Rhythm-reading games for music class. A little walker crosses a scrolling staff, and players tap on the start of every note.

- **Marathon** (`index.html`): one long run that adds half, whole and eighth notes, rests, ties, sixteenths and triplets as you go, at a steady 70 bpm. Three lives, and a high score list saved on each device.
- **Levels** (`levels.html`): nine separate levels, from quarter notes up to sixteenths.

Play: https://vvm26br2pj-max.github.io/note-walker/ (Marathon) and https://vvm26br2pj-max.github.io/note-walker/levels.html (Levels).

Each game is a single HTML file with no build step. Tap with the Space bar, the TAP button or the touchscreen.
